AniDeepth is built for motion designers who need fast depth layout inside After Effects without manually recalculating scale every time a layer moves.

  • Cloud layers
  • Parallax scenes

Workflow

Set the frame first. Adjust depth after.

01

Select layers

Auto load reads the selected layers into a compact table. Lock the table when the layout needs to stay fixed.

02

Choose movement

Use Camera Depth for camera-facing moves or World X, Y, Z for stable axis-based layout.

03

Drag interactively

Move layers live with sensitivity levels, modifier keys, undo, redo, and reset per layer.

Features

Depth tools that respect an animator's existing composition.

Preserve-view scale

Depth changes compensate scale so a designed frame stays visually consistent while the layer position changes.

Layer depth table

See current depth for selected layers, reorder the working list, and keep action controls close to each row.

Distribute modes

Together, Spread, Random Order, Random Depth, and Random Chaos cover clean spacing through playful variation.

Snap 3D objects

Snap one 3D layer to another at the current frame, optionally parent it, and choose below, same, or above depth.

Distribute

Five depth behaviors, named for memory.

Together

All selected layers move by the same amount.

Spread

Layers are evenly distributed by the table order.

Random Order

Even spacing, shuffled near and far positions.

Random Depth

Table order remains, depth rhythm becomes uneven.

Random Chaos

Both order and depth spacing become irregular.

FAQ

Before release.

Does it replace After Effects 3D?

No. It works with After Effects 3D layers and gives you a faster way to place them in depth.

Does it support Camera Depth and World axes?

Yes. Camera Depth is for camera-relative depth. World X, Y, and Z are stable axis modes.
